# Java — ArrayList e Stream API

Coleção de exercícios Java com foco em listas dinâmicas e processamento básico de dados com streams.

## Exemplos

- `Main.java` — cria e percorre um `ArrayList` de textos.
- `ArrayLists.java` — gera idades de exemplo, filtra adultos com `filter()`, ordena os resultados com `sorted()` e coleta os valores em uma lista.

## Conceitos

- `List` e `ArrayList`
- Generics
- Expressões lambda
- Pipeline de Stream
- `filter()`, `sorted()` e `collect()`

## Requisitos e execução

JDK 8 ou superior.

Compile e execute cada exemplo a partir da raiz do repositório:

```bash
javac -d out src/Main.java
java -cp out Main
```

```bash
javac -d out src/ArrayLists.java
java -cp out ArrayLists
```
