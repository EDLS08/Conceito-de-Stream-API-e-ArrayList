# Java — ArrayList and Stream API

A collection of Java exercises focused on dynamic lists and basic stream processing.

## Examples

- `Main.java` — creates and iterates over an `ArrayList` of strings.
- `ArrayLists.java` — generates sample ages, filters adults with `filter()`, sorts the results with `sorted()`, and collects them into a list.

## Concepts

- `List` and `ArrayList`
- Generics
- Lambda expressions
- Stream pipelines
- `filter()`, `sorted()`, and `collect()`

## Requirements and execution

JDK 8 or newer.

Compile and run either example from the repository root:

```bash
javac -d out src/Main.java
java -cp out Main
``

```bash
javac -d out src/ArrayLists.java
java -cp out ArrayLists
```
